# 🔐 Cyber Password Analyzer

Cyber Password Analyzer is an advanced password security tool built using **HTML, CSS, and JavaScript** with a cyber-themed interface.

It helps users analyze password strength, generate secure passwords, estimate crack time, and receive security suggestions with an interactive Matrix-style UI.

---

## ✨ Features

✅ Password Strength Detection  
✅ Strong Password Generator  
✅ AI Security Suggestions  
✅ Entropy Score Calculation  
✅ Password Crack Time Estimation  
✅ Matrix Rain Background  
✅ Glassmorphism UI  
✅ Show / Hide Password Option  
✅ Weak Password Warning Alert  
✅ Automatic Strong Password Recommendation  
✅ Hacker Terminal Logs
